rh-to-uw

Jump from an option in Robinhood to its Unusual Whales contract page.

Install

Drag this link onto your bookmarks bar:

RH to UW

Or add a bookmark by hand and paste this as its URL (click the box, select all, copy):

Use

  1. Click the bookmarklet.
  2. Click any option in your Robinhood portfolio.
  3. Unusual Whales opens in a new tab, already on that contract.

Works in Robinhood Classic and Legend. Esc cancels. The whole program is the link above; it talks to nothing except the Unusual Whales page it opens.
